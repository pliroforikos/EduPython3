# Είσοδος και έξοδος

## Πώς διαβάζω ακέραιους αριθμούς
@tags: input raw_input int ανάγνωση είσοδος πληκτρολόγιο ακέραιος
Η `raw_input()` επιστρέφει **πάντα κείμενο**. Για να γίνει ακέραιος αριθμός, το περνάμε από την `int()`.
```python
x = int(raw_input("Δώσε έναν ακέραιο: "))
print "Το διπλάσιο είναι", x * 2
```
Δύο τιμές, η μία μετά την άλλη:
```python
a = int(raw_input("Πρώτος αριθμός: "))
b = int(raw_input("Δεύτερος αριθμός: "))
print "Άθροισμα:", a + b
```
Όπως στο βιβλίο, μπορείς να χρησιμοποιήσεις και την `input()`, που δίνει κατευθείαν αριθμό:
```python
x = input("Δώσε έναν ακέραιο: ")
```
! Χωρίς `int()` η τιμή μένει κείμενο: `"5" + "3"` δίνει `"53"`, όχι `8`.
! Η `input()` της Python 2 **υπολογίζει** ό,τι γράψει ο χρήστης. Αν γράψει λέξη, βγαίνει `NameError`. Χρησιμοποίησέ τη μόνο για αριθμούς.
> Η `int()` κόβει το δεκαδικό μέρος ενός πραγματικού: `int(7.9)` → `7`. Το `int("7.9")` όμως βγάζει λάθος· για τέτοια είσοδο θέλεις `float()`.

## Πώς διαβάζω πραγματικούς (δεκαδικούς) αριθμούς
@tags: float raw_input input δεκαδικός πραγματικός ανάγνωση
```python
timi = float(raw_input("Τιμή προϊόντος: "))
fpa = timi * 0.24
print "ΦΠΑ:", fpa
print "Τελική τιμή:", timi + fpa
```
! Τα δεκαδικά γράφονται με **τελεία**: `12.5`, όχι `12,5`.
> Με `input()` το `12.5` διαβάζεται ως πραγματικός, αλλά το `12` ως ακέραιος. Με `float(raw_input())` έχεις **πάντα** πραγματικό, άρα και σωστές διαιρέσεις.

## Πώς διαβάζω κείμενο
@tags: raw_input string συμβολοσειρά όνομα λέξη ναι όχι
```python
onoma = raw_input("Πώς σε λένε; ")
poli = raw_input("Σε ποια πόλη μένεις; ")
print "Γεια σου", onoma, "από", poli
```
Απάντηση ναι/όχι:
```python
apantisi = raw_input("Θέλεις να συνεχίσεις; (Ν/Ο) ")
if apantisi == "Ν" or apantisi == "ν":
    print "Συνεχίζουμε!"
```
! Το κείμενο το διαβάζουμε **πάντα** με `raw_input()`, ποτέ με `input()`.
! Τα **ονόματα μεταβλητών** γράφονται με λατινικούς χαρακτήρες (`onoma`, όχι `όνομα`). Τα ελληνικά μπαίνουν μόνο μέσα σε εισαγωγικά.

## Πώς εμφανίζω κείμενα και μεταβλητές
@tags: print εμφάνιση οθόνη έξοδος μορφοποίηση str κόμμα % format δεκαδικά
### Με κόμματα (το πιο απλό)
Τα κόμματα βάζουν αυτόματα **ένα κενό** ανάμεσα στα στοιχεία. Οι αριθμοί δεν χρειάζονται μετατροπή.
```python
onoma = "Μαρία"
vathmos = 18.5
print "Η", onoma, "έγραψε", vathmos, "στις εξετάσεις."
```
```output
Η Μαρία έγραψε 18.5 στις εξετάσεις.
```
### Με + (ένωση κειμένων)
Το `+` ενώνει **μόνο κείμενα** και δεν βάζει κενά. Οι αριθμοί μετατρέπονται πρώτα με `str()`.
```python
vathmos = 18.5
print "Βαθμός: " + str(vathmos) + "/20"
```
```output
Βαθμός: 18.5/20
```
### Με μορφοποίηση %
Κάθε σύμβολο `%` μέσα στο κείμενο αντικαθίσταται με μια τιμή, με τη σειρά: `%d` ακέραιος, `%f` πραγματικός (`%.2f` με 2 δεκαδικά), `%s` κείμενο.
```python
onoma = "Μαρία"
mo = 15.6666
print "Ο μέσος όρος της %s είναι %.2f" % (onoma, mo)
print "Πέρασαν %d από τους %d μαθητές" % (12, 25)
```
```output
Ο μέσος όρος της Μαρία είναι 15.67
Πέρασαν 12 από τους 25 μαθητές
```
### Στην ίδια γραμμή και κενές γραμμές
```python
for i in range(1, 6):
    print i,          # κόμμα στο τέλος: συνεχίζει στην ίδια γραμμή
print                 # σκέτο print: αλλαγή γραμμής
print "Τέλος"
```
```output
1 2 3 4 5
Τέλος
```
! Στην Python 2 το `print` είναι εντολή: `print x`. Το `print(x, end="")` της Python 3 **δεν** υπάρχει.
! Με παρενθέσεις και κόμμα, `print("Βαθμός:", 5)`, εμφανίζεται πλειάδα: `('Βαθμός:', 5)`.
> Ειδικοί χαρακτήρες μέσα στο κείμενο: `"\n"` αλλαγή γραμμής, `"\t"` στηλοθέτης (tab).
> Μια λίστα με ελληνικά εμφανίζεται με κωδικούς (`['Άννα']` φαίνεται ως `['\xa2\xed\xed\xe1']`). Εμφάνισε τα στοιχεία ένα-ένα με `for` (ή δες τη λίστα στο πάνελ **Μεταβλητές**).

## Πράξεις και τελεστές
@exams: 2024 Α, 2025 Α2, 2026 Α2
@tags: τελεστές διαίρεση ακέραια πηλίκο υπόλοιπο mod div δύναμη pow divmod abs round αριθμητικοί
| Παράσταση | Αποτέλεσμα | Τι κάνει |
| `7 + 2` | `9` | πρόσθεση |
| `7 / 2` | `3` | διαίρεση **ακεραίων**: δίνει ακέραιο |
| `7 / 2.0` | `3.5` | αν ένας είναι πραγματικός, κανονική διαίρεση |
| `-7 / 2` | `-4` | στρογγυλεύει προς τα κάτω |
| `7 // 2` | `3` | ακέραιο πηλίκο |
| `7 % 2` | `1` | υπόλοιπο διαίρεσης |
| `45 % 10` | `5` | τελευταίο ψηφίο |
| `2 ** 3` | `8` | δύναμη |
| `4 / (2 ** 0)` | `4` | το `2 ** 0` είναι 1 |
| `pow(4, 2)` | `16` | δύναμη |
| `divmod(17, 5)` | `(3, 2)` | (πηλίκο, υπόλοιπο) |
| `divmod(2, 5)` | `(0, 2)` | το 5 «χωράει» 0 φορές στο 2 |
| `abs(-4)` | `4` | απόλυτη τιμή |
| `round(3.567, 2)` | `3.57` | στρογγυλοποίηση |
| `int(7.9)` | `7` | αποκοπή δεκαδικών |
| `float(3)` | `3.0` | μετατροπή σε πραγματικό |
| `int("5") ** 2` | `25` | κείμενο σε αριθμό |
| `str(5) * 2` | `'55'` | επανάληψη κειμένου |
| `len("Python")` | `6` | πλήθος χαρακτήρων |
### Μέσος όρος χωρίς παγίδα
```python
athroisma = 47
plithos = 3
print athroisma / plithos             # 15  (ακέραια διαίρεση!)
print float(athroisma) / plithos      # 15.6666666667
```
### Χρήσιμα με % και /
```python
x = 2357
print x % 10          # τελευταίο ψηφίο: 7
print x / 10          # χωρίς το τελευταίο ψηφίο: 235
print x % 2 == 0      # είναι άρτιος; False
print x % 5 == 0      # διαιρείται με το 5; False
```
> Προτεραιότητα: πρώτα `**`, μετά `*  /  //  %`, τέλος `+  -`. Με παρενθέσεις αλλάζεις τη σειρά: `(2 + 3) * 4` → `20`.
> Συντομεύσεις: `x += 1` σημαίνει `x = x + 1`, `x -= 2` σημαίνει `x = x - 2`.

## Συγκρίσεις και λογικοί τελεστές
@exams: 2025 Α2, 2026 Α2
@tags: and or not συνθήκη σύγκριση λογικές True False ίσο διάφορο πίνακας αλήθειας
| Παράσταση | Αποτέλεσμα |
| `5 == 5` | `True` (ίσο) |
| `5 != 3` | `True` (διάφορο) |
| `(5 < 2) or (4 >= 3)` | `True` |
| `(12 < 11) or (23 > 10)` | `True` |
| `not (34 != 45)` | `False` |
| `not (7 != 4 + 5) and (5 > 3)` | `False` |
| `3 < x < 10` | ίδιο με `x > 3 and x < 10` |
### Πίνακας αλήθειας
| A | B | A and B | A or B | not A |
| True | True | True | True | False |
| True | False | False | True | False |
| False | True | False | True | True |
| False | False | False | False | True |
- `and`: αληθές μόνο όταν **και τα δύο** είναι αληθή.
- `or`: αληθές όταν **ένα τουλάχιστον** είναι αληθές.
- `not`: αντιστρέφει την τιμή.
- Σειρά: πρώτα οι αριθμητικές πράξεις, μετά οι συγκρίσεις, μετά `not`, `and`, `or`.
! Σύγκριση γίνεται με `==`. Το σκέτο `=` είναι εκχώρηση τιμής.
! Γράψε `if x == 1 or x == 2:` και όχι `if x == 1 or 2:` (το δεύτερο είναι πάντα αληθές).
> Τα κείμενα συγκρίνονται αλφαβητικά: `"Anna" < "Nikos"` → `True`. Τα κεφαλαία μπαίνουν πριν από τα πεζά, και τα ελληνικά με τόνο δεν ταξινομούνται σωστά.

# Δομές ελέγχου (if, for, while)

## Πώς παίρνω απόφαση με if / elif / else
@tags: if elif else επιλογή απόφαση συνθήκη αν αλλιώς
```python
vathmos = float(raw_input("Βαθμός: "))
if vathmos >= 18.5:
    print "Άριστα"
elif vathmos >= 15:
    print "Πολύ καλά"
elif vathmos >= 10:
    print "Καλά"
else:
    print "Απορρίπτεται"
```
- Μετά από `if`, `elif`, `else` μπαίνει πάντα `:`.
- Οι εντολές του μπλοκ έχουν **εσοχή 4 κενά**.
- Από ένα `if/elif/else` εκτελείται **μόνο ένα** μπλοκ: του πρώτου αληθούς ελέγχου.
> Στα διαδοχικά `elif` δεν χρειάζεται να ξαναγράψεις το πάνω όριο (`vathmos >= 15 and vathmos < 18.5`): αν φτάσαμε εκεί, ο προηγούμενος έλεγχος βγήκε ψευδής.

## Κλιμακωτή χρέωση
@exams: 2022 Γ
@tags: κλίμακα κλιμακωτή χρέωση τιμολόγηση if elif κόστος συνάρτηση
### Η τιμή ανά τεμάχιο εξαρτάται από την ποσότητα
Π.χ. 1-3 τεμάχια 120 € το καθένα, 4-6 τεμάχια 100 €, 7 και πάνω 70 €.
```python
def ypologismos(temaxia):
    if temaxia <= 3:
        poso = temaxia * 120
    elif temaxia <= 6:
        poso = temaxia * 100
    else:
        poso = temaxia * 70
    return poso

print ypologismos(5)     # 500
```
### Κάθε κλίμακα χρεώνεται με τη δική της τιμή
Π.χ. νερό: τα πρώτα 10 κυβικά 0.5 € το καθένα, από 10 έως 30 κυβικά 0.8 €, πάνω από 30 κυβικά 1.2 €.
```python
def xreosi(kyvika):
    if kyvika <= 10:
        poso = kyvika * 0.5
    elif kyvika <= 30:
        poso = 10 * 0.5 + (kyvika - 10) * 0.8
    else:
        poso = 10 * 0.5 + 20 * 0.8 + (kyvika - 30) * 1.2
    return poso

print xreosi(35)     # 5 + 16 + 6 = 27.0
```
> Στη δεύτερη περίπτωση κάθε κλίμακα πληρώνεται **ολόκληρη** πριν περάσεις στην επόμενη: για 35 κυβικά, 10 με 0.5 + 20 με 0.8 + 5 με 1.2.

## Επανάληψη for με range
@tags: for range βρόχος επανάληψη μετρητής βήμα
```python
for i in range(5):
    print i            # 0, 1, 2, 3, 4
```
| Εντολή | Τιμές του i |
| `range(5)` | 0, 1, 2, 3, 4 |
| `range(1, 6)` | 1, 2, 3, 4, 5 |
| `range(2, 11, 2)` | 2, 4, 6, 8, 10 |
| `range(10, 0, -1)` | 10, 9, …, 1 |
| `range(10, -1, -1)` | 10, 9, …, 0 |
| `range(5, 1)` | καμία (κενή) |
Διάσχιση λίστας ή κειμένου:
```python
for onoma in ["Άννα", "Νίκος", "Ελένη"]:
    print "Καλημέρα", onoma
for gramma in "ΕΠΑΛ":
    print gramma
```
! Το τέλος **δεν** περιλαμβάνεται: `range(1, 10)` σταματά στο 9. Για 1 έως Ν γράψε `range(1, N + 1)`.
> Το `for` χρησιμοποιείται όταν ξέρουμε **από πριν** πόσες επαναλήψεις θα γίνουν.

## Επανάληψη while
@tags: while βρόχος επανάληψη συνθήκη ατέρμων break
```python
i = 1
while i <= 5:
    print i
    i = i + 1      # χωρίς αυτή τη γραμμή: ατέρμων βρόχος!
```
- Η συνθήκη ελέγχεται **πριν** από κάθε επανάληψη. Αν είναι ψευδής από την αρχή, το μπλοκ δεν εκτελείται ποτέ.
- Χρησιμοποιείται όταν **δεν ξέρουμε** από πριν πόσες επαναλήψεις θα γίνουν (τιμή τερματισμού, έλεγχος εγκυρότητας).
### Επανάληψη «μέχρις ότου» με break
Η Python δεν έχει «Μέχρις_ότου». Το μιμούμαστε με `while True:` και `break`, που βγάζει αμέσως από τον βρόχο:
```python
while True:
    x = int(raw_input("Δώσε θετικό αριθμό: "))
    if x > 0:
        break
print "Έδωσες", x
```
! Αν η συνθήκη δεν γίνει ποτέ ψευδής, το πρόγραμμα «κολλάει». Σταμάτησέ το με **■ Διακοπή** (Ctrl+F2).

## Μετατροπή for σε while και αντίστροφα
@exams: 2023 Β2, 2024 Β3, 2026 Β3
@tags: μετατροπή for while ισοδύναμο range μετρητής
Ένα `for i in range(arxi, telos, vima)` γίνεται `while` σε τρία βήματα: **αρχική τιμή** πριν από το `while`, **συνθήκη** στο `while`, **αύξηση** στο τέλος του μπλοκ.
```python
for i in range(1, 10, 2):
    print i
```
```python
i = 1
while i < 10:
    print i
    i = i + 2
```
### Με αρνητικό βήμα η σύγκριση αλλάζει φορά
```python
for j in range(10, -1, -1):
    print j
```
```python
j = 10
while j > -1:          # ή: while j >= 0
    print j
    j = j - 1
```
### Από while σε for
Το `while i <= 10` περιλαμβάνει το 10, ενώ το `range` σταματά πριν από το τέλος· γι' αυτό το τέλος γίνεται 11.
```python
S = 0
i = 1
while i <= 10:
    S = S + i
    print S
    i = i + 2
```
```python
S = 0
for i in range(1, 11, 2):
    S = S + i
    print S
```
### Ένθετοι βρόχοι
```python
i = 1
while i <= 3:
    j = 5
    while j >= 1:
        print i, j
        j = j - 1
    i = i + 1
```
```python
for i in range(1, 4):
    for j in range(5, 0, -1):
        print i, j
```
! Στους ένθετους `while`, η αρχική τιμή του εσωτερικού μετρητή (`j = 5`) μπαίνει **μέσα** στον εξωτερικό βρόχο, ώστε να ξεκινά από την αρχή κάθε φορά.

## Ένθετοι βρόχοι
@tags: ένθετοι φωλιασμένοι διπλός βρόχος πίνακας πολλαπλασιασμού σχήματα αστεράκια
Για κάθε επανάληψη του εξωτερικού βρόχου, ο εσωτερικός εκτελείται **ολόκληρος**.
```python
for i in range(1, 4):
    for j in range(1, 4):
        print i * j,
    print
```
```output
1 2 3
2 4 6
3 6 9
```
```python
for i in range(1, 5):
    print "*" * i
```
```output
*
**
***
****
```
> Συνολικές επαναλήψεις: (επαναλήψεις εξωτερικού) × (επαναλήψεις εσωτερικού). Π.χ. 10 πόλεις × 30 ημέρες = 300 αναγνώσεις.

# Κλασικοί αλγόριθμοι

## Επαναληπτική ανάγνωση γνωστού πλήθους τιμών
@tags: ανάγνωση επανάληψη for διαβάζω πολλές τιμές πλήθος
Όταν ξέρουμε πόσες τιμές θα δοθούν, χρησιμοποιούμε `for`.
```python
for i in range(10):
    vathmos = float(raw_input("Βαθμός " + str(i + 1) + ": "))
    print "Διάβασα", vathmos
```
Με ένθετο βρόχο, π.χ. για κάθε πόλη 30 θερμοκρασίες:
```python
for i in range(10):
    poli = raw_input("Πόλη: ")
    for j in range(30):
        t = float(raw_input("Θερμοκρασία ημέρας " + str(j + 1) + ": "))
```
> Η μεταβλητή παίρνει **νέα τιμή σε κάθε επανάληψη** και η προηγούμενη χάνεται. Είτε την επεξεργάζεσαι αμέσως (άθροισμα, μέγιστο, πλήθος…) είτε την αποθηκεύεις σε λίστα.

## Επαναληπτική ανάγνωση μέχρι μια τιμή τερματισμού
@exams: 2022 Δ
@tags: φρουρός τέλος ΤΕΛΟΣ τερματισμός while άγνωστο πλήθος συνέχεια
Όταν **δεν ξέρουμε** πόσες τιμές θα δοθούν: διαβάζουμε μία φορά **πριν** από το `while` και ξανά στο **τέλος** του μπλοκ.
```python
athroisma = 0
x = int(raw_input("Δώσε αριθμό (0 για τέλος): "))
while x != 0:
    athroisma = athroisma + x
    x = int(raw_input("Δώσε αριθμό (0 για τέλος): "))
print "Άθροισμα:", athroisma
```
Με λέξη τερματισμού:
```python
onoma = raw_input("Όνομα (ΤΕΛΟΣ για τέλος): ")
while onoma != "ΤΕΛΟΣ":
    vathmos = float(raw_input("Βαθμός: "))
    print onoma, vathmos
    onoma = raw_input("Όνομα (ΤΕΛΟΣ για τέλος): ")
```
Με ερώτηση «Συνέχεια;»:
```python
apantisi = "Ν"
while apantisi == "Ν":
    x = int(raw_input("Αριθμός: "))
    print "Το τετράγωνο είναι", x * x
    apantisi = raw_input("Συνέχεια; (Ν/Ο) ")
```
! Η τιμή τερματισμού (0, «ΤΕΛΟΣ») **δεν** επεξεργάζεται: δεν μπαίνει στο άθροισμα, στο πλήθος ή στη λίστα. Γι' αυτό η δεύτερη ανάγνωση γίνεται στο **τέλος** του μπλοκ.

## Έλεγχος εγκυρότητας τιμών
@exams: 2022 Δ, 2023 Γ, 2024 Γ, 2025 Γ
@tags: εγκυρότητα έλεγχος validation αποδεκτή τιμή όρια ξαναδώσε λάθος τιμή
Ξαναζητάμε την τιμή **όσο** είναι λάθος.

## Εμβέλεια μεταβλητών
@tags: εμβέλεια τοπική καθολική global local
```python
x = 10                 # καθολική (global)

def f():
    y = 5              # τοπική: υπάρχει μόνο μέσα στη f
    print x, y         # την καθολική x τη «βλέπει»

def g():
    global x           # για να ΑΛΛΑΞΕΙ η καθολική x
    x = x + 1

f()
g()
print x                # 11
```
- Οι μεταβλητές που δημιουργούνται μέσα σε μια συνάρτηση, και οι παράμετροί της, είναι **τοπικές**: χάνονται όταν τελειώσει η συνάρτηση.
- Αν μέσα σε συνάρτηση γίνει εκχώρηση σε μια μεταβλητή, η Python τη θεωρεί τοπική, εκτός αν δηλωθεί `global`.
! Μια τοπική μεταβλητή δεν υπάρχει έξω από τη συνάρτηση: εκεί το `print y` βγάζει `NameError`.
> Προτίμησε παραμέτρους και `return` αντί για `global`.

## Μέθοδοι λίστας (append, insert, pop…)
@exams: 2026 Β2
@tags: append insert pop remove index count sort reverse del in προσθήκη διαγραφή εισαγωγή
| Εντολή | Τι κάνει | Με L = [5, 8, 3] |
| `L.append(x)` | προσθήκη στο τέλος | `L.append(9)` → `[5, 8, 3, 9]` |
| `L.insert(i, x)` | εισαγωγή στη θέση i | `L.insert(1, 7)` → `[5, 7, 8, 3]` |
| `L.pop()` | αφαιρεί **και επιστρέφει** το τελευταίο | δίνει `3`, L = `[5, 8]` |
| `L.pop(i)` | αφαιρεί και επιστρέφει το στοιχείο της θέσης i | `L.pop(0)` δίνει `5`, L = `[8, 3]` |
| `L.remove(x)` | αφαιρεί την πρώτη εμφάνιση της **τιμής** x | `L.remove(8)` → `[5, 3]` |
| `del L[i]` | διαγράφει τη θέση i | `del L[0]` → `[8, 3]` |
| `L.index(x)` | θέση της πρώτης εμφάνισης του x | `L.index(3)` → `2` |
| `L.count(x)` | πόσες φορές υπάρχει το x | `L.count(5)` → `1` |
| `x in L` | υπάρχει το x; | `8 in L` → `True` |
| `L.sort()` | ταξινόμηση σε αύξουσα | → `[3, 5, 8]` |
| `L.sort(reverse=True)` | ταξινόμηση σε φθίνουσα | → `[8, 5, 3]` |
| `L.reverse()` | αντιστροφή | → `[3, 8, 5]` |
| `L + [1, 2]` | ένωση σε νέα λίστα | → `[5, 8, 3, 1, 2]` |
| `sorted(L)` | νέα ταξινομημένη λίστα (η L μένει ίδια) | → `[3, 5, 8]` |
### Βήμα-βήμα
```python
on = ["MARIA", "NIKOS", "LAZAROS"]
on = ["MANOLIS"] + on
print on          # ['MANOLIS', 'MARIA', 'NIKOS', 'LAZAROS']
on.pop()
print on          # ['MANOLIS', 'MARIA', 'NIKOS']
on.insert(2, "ADAM")
print on          # ['MANOLIS', 'MARIA', 'ADAM', 'NIKOS']
on.pop(1)
print on          # ['MANOLIS', 'ADAM', 'NIKOS']
on = on + ["ANNA"]
print on          # ['MANOLIS', 'ADAM', 'NIKOS', 'ANNA']
```
! Το `lista = lista.sort()` κάνει τη λίστα `None`! Η `sort()` ταξινομεί **την ίδια** τη λίστα και δεν επιστρέφει τίποτα. Γράψε σκέτο `lista.sort()`.
! Το `remove(x)` αφαιρεί **τιμή**, ενώ το `pop(i)` αφαιρεί **θέση**.

## Δυαδική αναζήτηση
@exams: 2024 Β2
@tags: δυαδική αναζήτηση binary search ταξινομημένη μέσο mid
Μόνο σε **ταξινομημένη** λίστα. Συγκρίνουμε με το μεσαίο στοιχείο και κρατάμε το μισό όπου μπορεί να βρίσκεται.
```python
def binarySearch(array, key):
    first = 0
    last = len(array) - 1
    pos = -1
    while first <= last and pos == -1:
        mid = (first + last) / 2
        if array[mid] == key:
            pos = mid
        elif array[mid] < key:
            first = mid + 1
        else:
            last = mid - 1
    return pos

print binarySearch([7, 12, 29, 31, 42, 73, 98, 145], 98)    # 6
```
### Εκτέλεση με το χέρι
Αναζήτηση του 98 στη λίστα `[7, 12, 29, 31, 42, 73, 98, 145]`:
| first | last | mid | array[mid] | ενέργεια |
| 0 | 7 | 3 | 31 | 31 < 98, άρα first = 4 |
| 4 | 7 | 5 | 73 | 73 < 98, άρα first = 6 |
| 6 | 7 | 6 | 98 | βρέθηκε στη θέση 6 |
Αν το στοιχείο δεν υπάρχει, κάποια στιγμή `first > last` και η συνάρτηση επιστρέφει `-1`.
! Σε λίστα με **φθίνουσα** σειρά (π.χ. `[235, 181, 145, 98, …]`) αντιστρέφεται η σύγκριση: όταν `array[mid] > key`, τότε `first = mid + 1`.
> Το `(first + last) / 2` είναι ακέραια διαίρεση στην Python 2: για 4 και 7 δίνει 5.

## Ταξινόμηση φυσαλίδας (ευθείας ανταλλαγής)
@exams: 2023 Β3, 2024 Δ, 2025 Δ, 2026 Δ
@tags: ταξινόμηση φυσαλίδα ευθεία ανταλλαγή bubble sort αύξουσα φθίνουσα ανταλλαγή
```python
def bubbleSort(array):
    N = len(array)
    for i in range(N - 1):
        for j in range(N - 1, i, -1):
            if array[j] < array[j - 1]:
                array[j], array[j - 1] = array[j - 1], array[j]

lista = [7, 8, 3, 4, -2]
bubbleSort(lista)
print lista            # [-2, 3, 4, 7, 8]
```
### Βήμα-βήμα
Σε κάθε πέρασμα, το μικρότερο από τα αταξινόμητα «ανεβαίνει» στην αρχή, σαν φυσαλίδα.
| Πέρασμα | Λίστα μετά το πέρασμα |
| αρχή | 7, 8, 3, 4, -2 |
| 1ο | -2, 7, 8, 3, 4 |
| 2ο | -2, 3, 7, 8, 4 |
| 3ο | -2, 3, 4, 7, 8 |
| 4ο | -2, 3, 4, 7, 8 |
### Φθίνουσα σειρά, μαζί με παράλληλη λίστα
Αλλάζει μόνο η σύγκριση (`>` αντί για `<`). Ό,τι ανταλλάσσεται στη μία λίστα, ανταλλάσσεται και στην άλλη.
```python
def taxinomisi(SALES, TITLES):
    N = len(SALES)
    for i in range(N - 1):
        for j in range(N - 1, i, -1):
            if SALES[j] > SALES[j - 1]:
                SALES[j], SALES[j - 1] = SALES[j - 1], SALES[j]
                TITLES[j], TITLES[j - 1] = TITLES[j - 1], TITLES[j]
```
### Σε ισοβαθμία, δεύτερο κριτήριο αλφαβητικά
```python
def taxinomisi(S_POSO, ON):
    N = len(S_POSO)
    for i in range(N - 1):
        for j in range(N - 1, i, -1):
            if S_POSO[j] > S_POSO[j - 1] or (S_POSO[j] == S_POSO[j - 1] and ON[j] < ON[j - 1]):
                S_POSO[j], S_POSO[j - 1] = S_POSO[j - 1], S_POSO[j]
                ON[j], ON[j - 1] = ON[j - 1], ON[j]
```
> Ανταλλαγή τιμών: `a, b = b, a`. Ή με βοηθητική μεταβλητή: `temp = a`, `a = b`, `b = temp`.
> Η έτοιμη `lista.sort()` κάνει την ίδια δουλειά, αλλά στις εξετάσεις συνήθως ζητείται ο αλγόριθμος.

## Ταξινόμηση με εισαγωγή
@tags: ταξινόμηση εισαγωγή insertion sort
Κάθε στοιχείο «εισάγεται» στη σωστή θέση ανάμεσα στα προηγούμενα, που είναι ήδη ταξινομημένα (όπως τακτοποιούμε τα χαρτιά στο χέρι).
```python
def insertionSort(array):
    for i in range(1, len(array)):
        value = array[i]
        j = i
        while j > 0 and array[j - 1] > value:
            array[j] = array[j - 1]
            j = j - 1
        array[j] = value

lista = [45, 12, 98, 3]
insertionSort(lista)
print lista            # [3, 12, 45, 98]
```

# Στοίβα και ουρά

## Στοίβα (LIFO)
@tags: στοίβα stack LIFO push pop ώθηση απώθηση κορυφή
**LIFO** (Last In, First Out): ό,τι μπήκε **τελευταίο** βγαίνει **πρώτο**, όπως σε μια στοίβα από πιάτα.
```python
stack = []
stack.append(5)        # ώθηση (push) στην κορυφή
stack.append(8)
stack.append(2)
print stack            # [5, 8, 2]  (κορυφή το 2)
x = stack.pop()        # απώθηση (pop) από την κορυφή
print x, stack         # 2 [5, 8]
print stack[-1]        # η κορυφή, χωρίς να αφαιρεθεί: 8
print len(stack) == 0  # είναι άδεια; False
```
Με συναρτήσεις, όπως στο βιβλίο:
```python
def createStack():
    return []

def push(stack, item):
    stack.append(item)

def pop(stack):
    return stack.pop()

def isEmpty(stack):
    return len(stack) == 0

s = createStack()
push(s, 10)
push(s, 20)
while not isEmpty(s):
    print pop(s)       # 20, μετά 10
```
! Η λίστα της Python **δεν** έχει `push`: χρησιμοποίησε `append`.
! Το `pop()` σε άδεια στοίβα βγάζει `IndexError`. Έλεγξε πρώτα ότι δεν είναι άδεια.

## Ουρά (FIFO)
@exams: 2026 Α1
@tags: ουρά queue FIFO enqueue dequeue εισαγωγή εξαγωγή
**FIFO** (First In, First Out): όποιος μπήκε **πρώτος** βγαίνει **πρώτος**, όπως στην ουρά του ταμείου.
```python
queue = []
queue.append("Μαρία")      # εισαγωγή (enqueue) στο τέλος
queue.append("Κώστας")
queue.append("Δήμητρα")
proti = queue.pop(0)       # εξαγωγή (dequeue) από την αρχή
print proti, "εξυπηρετείται. Περιμένουν", len(queue)
```
```output
Μαρία εξυπηρετείται. Περιμένουν 2
```
> Στη στοίβα βγάζουμε με `pop()` (από το τέλος), στην ουρά με `pop(0)` (από την αρχή). Και στις δύο προσθέτουμε με `append`.

```python
import sqlite3

conn = sqlite3.connect("mathites.db")
curs = conn.cursor()
curs.execute("CREATE TABLE IF NOT EXISTS mathites (onoma TEXT, vathmos REAL)")
curs.execute("INSERT INTO mathites VALUES (?, ?)", ("Anna", 18.5))
conn.commit()
curs.execute("SELECT onoma, vathmos FROM mathites WHERE vathmos >= 10")
for row in curs.fetchall():
    print row[0], row[1]
conn.close()
```

# Συχνές παγίδες

## Συχνές παγίδες της Python 2
@tags: λάθη παγίδες προσοχή συχνά εσοχή άνω κάτω τελεία ίσον διαίρεση
- Μετά από `if`, `elif`, `else`, `for`, `while`, `def`, `class` μπαίνει **`:`** και η επόμενη γραμμή έχει εσοχή.
- `==` για σύγκριση, `=` για εκχώρηση.
- `7 / 2` δίνει `3`: για δεκαδικό αποτέλεσμα `7 / 2.0` ή `float(7) / 2`.
- Το `raw_input()` δίνει **κείμενο**: για αριθμούς `int(...)` ή `float(...)`.
- Για ένωση κειμένου με αριθμό: `"Βαθμός: " + str(v)` ή `print "Βαθμός:", v`.
- Το `range(1, 10)` **δεν** περιλαμβάνει το 10.
- Οι θέσεις λίστας ξεκινούν από **0**· η τελευταία είναι η `len(L) - 1`.
- Οι αθροιστές και οι μετρητές παίρνουν αρχική τιμή **πριν** από τον βρόχο.
- Μετά την τιμή τερματισμού δεν επεξεργαζόμαστε τίποτα: η δεύτερη ανάγνωση μπαίνει στο **τέλος** του `while`.
- `lista.sort()` σκέτο, **όχι** `lista = lista.sort()`.
- Ονόματα μεταβλητών με **λατινικούς** χαρακτήρες, χωρίς κενά, και όχι λέξεις όπως `max`, `min`, `sum`, `list`, `str`.
> Όταν κάτι πάει στραβά, άνοιξε τον **Βοηθό** (F7): εξηγεί κάθε λάθος στα ελληνικά.
