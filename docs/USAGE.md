## 1. Εγκατάσταση & Εκκίνηση

### Απαιτήσεις
- **Λειτουργικό Σύστημα:** Windows 10 / 11 ή Linux 64-bit (Ubuntu, Linux Mint, Debian).
- **Python 3:** Έκδοση **3.10 έως 3.14** (λήψη από το [python.org](https://www.python.org/downloads/) για Windows ή μέσω του διαχειριστή πακέτων της διανομής για Linux).

### Εκδόσεις Windows
1. **Εγκατάσταση (`EduPython3-<έκδοση>-setup.exe`):**
   - Εγκαθιστά την εφαρμογή για όλους τους χρήστες του υπολογιστή (`Program Files`).
   - Δημιουργεί συντόμευση στην επιφάνεια εργασίας και στο μενού Έναρξη.
   - Συσχετίζει αυτόματα τα αρχεία `.py` με το EduPython3.
2. **Φορητή Έκδοση (`EduPython3-<έκδοση>-portable.exe`):**
   - Ένα ενιαίο αρχείο `.exe` που εκτελείται άμεσα, χωρίς εγκατάσταση.
   - Ιδανικό για εκτέλεση από USB flash drive ή σε σχολικά εργαστήρια χωρίς δικαιώματα διαχειριστή.

### Έκδοση Linux
- Εγκατάσταση πακέτου Debian/Ubuntu: `sudo apt install ./edupython3_<έκδοση>_amd64.deb`
- Εξασφαλίστε ότι είναι εγκατεστημένο το γραφικό πακέτο: `sudo apt install python3 python3-tk`

## 2. Το Περιβάλλον Εργασίας

Η διεπαφή του EduPython3 χωρίζεται σε τρεις βασικές περιοχές:

```
+--------------------------------------------------------------+
| [▶ Εκτέλεση (F5)] [■ Διακοπή] [Ρυθμιστής Ταχύτητας] [F6][F7][F8] |  (Μπάρα Εργαλείων)
+------------------------------------+-------------------------+
|                                    |                         |
|           MONACO EDITOR            |     ΔΕΞΙ ΠΑΝΕΛ          |
|    (Κώδικας, Καρτέλες αρχείων,     |  • Μεταβλητές (F6)      |
|     Αρίθμηση γραμμών, Σφάλματα)    |  • Βοηθός λαθών (F7)    |
|                                    |  • Θέλω να θυμηθώ (F8)  |
|                                    |                         |
+------------------------------------+-------------------------+
|                                                              |
|                     SHELL (ΤΕΡΜΑΤΙΚΟ)                        |
|  (Έξοδος προγράμματος, Είσοδος input, Άμεση γραμμή >>>)      |
|                                                              |
+--------------------------------------------------------------+
```

1. **Editor (Επάνω αριστερά):**
   - Σύγχρονος επεξεργαστής κώδικα (Monaco) με χρωματισμό σύνταξης τύπου IDLE.
   - Αυτόματη συμπλήρωση εντολών (`Ctrl+Space`) με ελληνικές περιγραφές.
   - Αυτόματη εσοχή (indentation) 4 κενών μετά από άνω-κάτω τελεία (`:`).
   - Υποστήριξη καρτελών για ταυτόχρονη επεξεργασία πολλαπλών αρχείων.
2. **Shell (Κάτω μέρος):**
   - Εμφανίζει την έξοδο του προγράμματος (`print`).
   - Δέχεται την είσοδο του χρήστη απευθείας στη ροή του κειμένου.
   - Μετά την ολοκλήρωση της εκτέλεσης, προσφέρει άμεση γραμμή εντολών `>>>` με πρόσβαση στις μεταβλητές του προγράμματος και ιστορικό εντολών με τα βέλη `↑` / `↓`.
3. **Δεξί Πάνελ (Εναλλαγή με F6, F7, F8):**
   - **Μεταβλητές (F6):** Ζωντανή παρακολούθηση τιμών, τύπων και συναρτήσεων.
   - **Βοηθός λαθών (F7):** Φιλική επεξήγηση λαθών στα ελληνικά.
   - **Θέλω να θυμηθώ (F8):** Οδηγός αλγορίθμων και συντακτικού με παραδείγματα.

## 3. Συγγραφή και Εκτέλεση Προγραμμάτων

### Δημιουργία Νέου Αρχείου
Κάθε νέο αρχείο (`Ctrl+N`) δημιουργείται αυτόματα με έτοιμη φόρμα σχολίων για το σχολείο:
```python
###########################################################
# Ημερομηνία: 27/10/2026
# Άσκηση: 
# Ονοματεπώνυμο: 
# Τμήμα: 
###########################################################
```
Ο κέρσορας τοποθετείται αυτόματα στη γραμμή «Άσκηση:».

### Αποθήκευση
- Με `Ctrl+S` ή **Αρχείο → Αποθήκευση**.
- Η εφαρμογή αποθηκεύει από προεπιλογή στον φάκελο `EduPython3` μέσα στα **Έγγραφα** του χρήστη.
- Όλα τα αρχεία αποθηκεύονται σε κωδικοποίηση **UTF-8**. Αν ανοίξετε παλιό αρχείο από Python 2 (σε cp1253), η εφαρμογή το αναγνωρίζει και το μετατρέπει αυτόματα σε UTF-8.

### Εκτέλεση
- Πατήστε **▶ Εκτέλεση** ή το πλήκτρο **F5**.
- Το πρόγραμμα αποθηκεύεται αυτόματα και ξεκινά η εκτέλεσή του στο Shell.
- Για να σταματήσετε ένα πρόγραμμα που έχει «κολλήσει» (π.χ. ατέρμονος βρόχος `while`), πατήστε **■ Διακοπή** ή **Ctrl+F2**.

## 4. Εκτέλεση Βήμα-Βήμα και Ρύθμιση Ταχύτητας

Δίπλα στο κουμπί **■ Διακοπή** υπάρχει ο **ρυθμιστής ταχύτητας εκτέλεσης**:

| Ρύθμιση | Πώς λειτουργεί |
|---|---|
| **Γραμμή γραμμή** | Το πρόγραμμα σταματά πριν από κάθε γραμμή. Προχωράτε στην επόμενη πατώντας το κουμπί **Επόμενη** ή το πλήκτρο **F10**. |
| **Αργή** | Το πρόγραμμα εκτελεί αυτόματα μία γραμμή κάθε 1 δευτερόλεπτο. |
| **Μέτρια** | Το πρόγραμμα εκτελεί αυτόματα μία γραμμή κάθε 0,4 δευτερόλεπτα. |
| **Κανονική** | Κανονική εκτέλεση σε πραγματική ταχύτητα (χωρίς καθυστέρηση). |

Κατά την εκτέλεση βήμα-βήμα:
- Η γραμμή που πρόκειται να εκτελεστεί φωτίζεται με **κίτρινο χρώμα** και ένα βέλος **➜**.
- Στο πάνελ **Μεταβλητές** (F6) βλέπετε τις τιμές των μεταβλητών να ενημερώνονται ζωντανά.
- Μπορείτε να αλλάξετε την ταχύτητα οποιαδήποτε στιγμή ενώ το πρόγραμμα τρέχει.

## 5. Είσοδος & Έξοδος στην Python 3

### Είσοδος δεδομένων (`input`)
Στην Python 3 η συνάρτηση `input()` επιστρέφει **πάντα συμβολοσειρά (κείμενο)**:
```python
# Ανάγνωση κειμένου:
onoma = input("Πώς σε λένε; ")

# Ανάγνωση ακεραίου (μετατροπή με int):
etos = int(input("Έτος γέννησης: "))

# Ανάγνωση δεκαδικού (μετατροπή με float):
vathmos = float(input("Βαθμός: "))
```

### Έξοδος δεδομένων (`print`)
Στην Python 3 το `print` είναι **συνάρτηση** και απαιτεί παρενθέσεις:
```python
# Απλή εμφάνιση με κόμματα (προστίθεται αυτόματα κενό):
print("Γεια σου", onoma, "έχεις βαθμό", vathmos)

# Σύγχρονη μορφοποίηση με f-strings:
print(f"Ο μαθητής {onoma} έχει βαθμό {vathmos:.1f}/20")

# Εμφάνιση στην ίδια γραμμή:
for i in range(1, 6):
    print(i, end=" ")
print()  # αλλαγή γραμμής
```

### Διαίρεση: `/` vs `//`
- **`/` (κανονική διαίρεση):** Δίνει **πάντα πραγματικό αποτέλεσμα (float)**, π.χ. `7 / 2` → `3.5`.
- **`//` (ακέραιο πηλίκο):** Δίνει μόνο το ακέραιο μέρος, π.χ. `7 // 2` → `3`.

## 6. Ο Βοηθός Λαθών (F7)

Όταν ένα πρόγραμμα περιέχει λάθος κατά τη μεταγλώττιση ή την εκτέλεση:
1. Η γραμμή του λάθους κοκκινίζει στον editor.
2. Το Shell εμφανίζει το κόκκινο traceback. Μπορείτε να κάνετε **κλικ στο μπλε όνομα αρχείου** για να μεταβείτε απευθείας στη γραμμή του λάθους.
3. Ανοίγει αυτόματα ο **Βοηθός λαθών (F7)** στη δεξιά στήλη.

### Τι προσφέρει ο Βοηθός:
- **Ελληνικός τίτλος & επεξήγηση:** Εξηγεί με απλά λόγια τι σημαίνει το σφάλμα (π.χ. «Λείπει άνω-κάτω τελεία :», «Σύγκριση κειμένου με αριθμό», «Δείκτης λίστας εκτός ορίων»).
- **Συμβουλή διόρθωσης:** Προτείνει συγκεκριμένες ενέργειες για την επίλυση του προβλήματος.
- **Παράδειγμα Λάθος / Σωστό:** Δείχνει παραστατικά πώς γράφεται σωστά ο κώδικας.
- **Διόρθωση εισαγωγικών:** Αν αντιγράψετε κώδικα από PDF ή Word και εμφανιστούν καμπύλα εισαγωγικά (`“ ”`), η εντολή **Επεξεργασία → Διόρθωση εισαγωγικών** τα διορθώνει αυτόματα σε κανονικά εισαγωγικά (`"`).

## 7. Πάνελ Μεταβλητών (F6)

Πατώντας **F6** εμφανίζεται το πάνελ των μεταβλητών του προγράμματος:
- Καταγράφει όλες τις καθολικές μεταβλητές, τις τιμές τους και τον τύπο τους στα ελληνικά (`ακέραιος`, `πραγματικός`, `κείμενο`, `λίστα`, `λογική τιμή`).
- Για λίστες και συμβολοσειρές εμφανίζει και το μήκος τους (`len`).
- Κατά την εκτέλεση μιας συνάρτησης, εμφανίζει ξεχωριστά τις **τοπικές μεταβλητές** της συνάρτησης.
- Εμφανίζει επίσης τις συναρτήσεις που έχουν οριστεί στο πρόγραμμα με την παράμετρο και τη γραμμή ορισμού τους.

## 8. «Θέλω να θυμηθώ» (F8)

Το κουμπί **Θέλω να θυμηθώ (F8)** ανοίγει έναν πλήρη οδηγό με τους **45 βασικούς αλγορίθμους και εντολές της σχολικής ύλης**, ταξινομημένους σε 11 κατηγορίες:

1. **Είσοδος και έξοδος** (ακέραιοι, δεκαδικοί, κείμενο, print, πράξεις, τελεστές).
2. **Δομές ελέγχου** (if/elif/else, κλιμακωτή χρέωση, for, while, μετατροπές, ένθετοι βρόχοι).
3. **Κλασικοί αλγόριθμοι** (άθροισμα, μέσος όρος, πλήθος, ποσοστό, μέγιστο/ελάχιστο, τιμή τερματισμού, έλεγχος εγκυρότητας, ψηφία/διαιρέτες).
4. **Συναρτήσεις** (ορισμός def, παράμετροι, return, εμβέλεια global/local, βιβλιοθήκες math/random).
5. **Λίστες** (δείκτες, append, pop, παράλληλες λίστες, σειριακή αναζήτηση, δυαδική αναζήτηση, ταξινόμηση φυσαλίδας, ταξινόμηση εισαγωγής, σημαία).
6. **Συμβολοσειρές** (τεμαχισμός slicing, διάσχιση χαρακτήρων, μέθοδοι upper/lower/split/join κ.ά.).
7. **Στοίβα και ουρά** (LIFO με append/pop, FIFO με append/pop(0)).
8. **Αρχεία** (εγγραφή write, ανάγνωση read/readline με UTF-8).
9. **Κλάσεις και αντικείμενα** (class, __init__, μέθοδοι, ιδιότητες, self).
10. **Επιπλέον θέματα** (λεξικά dict, γραφικά παράθυρα Tkinter, βάσεις δεδομένων SQLite).
11. **Συχνές παγίδες** (όλα τα κλασικά λάθη αρχαρίων συγκεντρωμένα).

### Χαρακτηριστικά:
- **Φίλτρο Επιπέδου:** Επιλέξτε ανάμεσα σε **Όλα**, **Βασικά** (συνήθη θέματα Α/Β/Γ Γυμνασίου-Λυκείου) και **Προχωρημένα** (στοίβες, ουρές, δυαδική αναζήτηση, αρχεία, κλάσεις, γραφικά).
- **Αναζήτηση χωρίς τόνους:** Πληκτρολογήστε οποιαδήποτε λέξη (π.χ. `μεγιστο`, `αναζητηση`, `αρχειο`) για άμεση εύρεση του αντίστοιχου θέματος.
- **Σήμα Π:** Υποδεικνύει ότι ο συγκεκριμένος αλγόριθμος έχει ζητηθεί σε θέματα Πανελληνίων εξετάσεων ΕΠΑΛ (με αναφορά των ετών).
- **Κουμπί «Στον editor»:** Εισάγει άμεσα το παράδειγμα κώδικα στη θέση του κέρσορα.

## 9. Ρυθμίσεις & Ελληνικά Ονόματα

Από το μενού **Επεξεργασία → Ρυθμίσεις**:

1. **Διαδρομή Python 3:**
   - Η εφαρμογή εντοπίζει αυτόματα την εγκατεστημένη έκδοση Python 3.
   - Εάν έχετε πολλαπλές εγκαταστάσεις, μπορείτε να ορίσετε χειροκίνητα τη διαδρομή του επιθυμητού `python.exe`.
2. **Ελληνικά ονόματα μεταβλητών:**
   - **Προειδοποίηση (Προεπιλογή):** Επιτρέπει την εκτέλεση κώδικα με ελληνικά ονόματα (π.χ. `βαθμός = 18`), αλλά εμφανίζει διακριτική μπλε υπογράμμιση πληροφορίας υπενθυμίζοντας ότι στις εξετάσεις προτιμώνται λατινικοί χαρακτήρες.
   - **Απαγόρευση:** Υπογραμμίζει τα ελληνικά ονόματα με κόκκινο σφάλμα σύνταξης και διακόπτει την εκτέλεση (ιδανικό για προετοιμασία Πανελληνίων).
   - **Ελεύθερα:** Επιτρέπει πλήρως τα ελληνικά αναγνωριστικά χωρίς καμία ένδειξη.
3. **Κεντρικές Ρυθμίσεις Εργαστηρίου:**
   - Ο καθηγητής μπορεί να τοποθετήσει ένα αρχείο `defaults.json` στον φάκελο `%ProgramData%\EduPython3\` (Windows) ή `/etc/edupython3/` (Linux) για να επιβάλει ενιαίες ρυθμίσεις σε όλους τους υπολογιστές του εργαστηρίου.

## 10. Λειτουργία «Τάξη» στο Εργαστήριο

Η λειτουργία **Τάξη** επιτρέπει τη ζωντανή συνεργασία εκπαιδευτικού και μαθητών στο τοπικό δίκτυο του σχολικού εργαστηρίου, **χωρίς να απαιτείται σύνδεση στο διαδίκτυο**.

### Για τον Μαθητή:
1. **Σύνδεση:** Επιλέξτε **Τάξη → Σύνδεση στην τάξη…** και πληκτρολογήστε το τετραψήφιο **PIN** που εμφανίζει ο καθηγητής στην οθόνη του.
2. **Ενεργή Σύνδεση:** Κάτω δεξιά εμφανίζεται η ένδειξη `👁 Ο καθηγητής βλέπει τον κώδικά σου`. Κάνοντας κλικ εκεί μπορείτε να αποσυνδεθείτε ανά πάσα στιγμή.
3. **Σήκωμα Χεριού ✋:** Πατώντας το κουμπί **✋ Σηκώνω χέρι** ή το πλήκτρο **F9**, ειδοποιείται άμεσα ο καθηγητής ότι χρειάζεστε βοήθεια. Πατήστε το ξανά για να κατεβάσετε το χέρι.
4. **Παρουσίαση Καθηγητή:** Όταν ο καθηγητής ξεκινά παρουσίαση, βλέπετε ζωντανά τον κώδικά του και την έξοδο του Shell στην οθόνη σας. Αν ο καθηγητής ενεργοποιήσει το «🔒 Όλοι εδώ», ο επεξεργαστής σας κλειδώνει προσωρινά για να εστιάσετε στην παράδοση.
