# EduPython3

Εκπαιδευτικό περιβάλλον προγραμματισμού **Python 3** για μαθητές Γυμνασίου, Λυκείου, ΕΠΑΛ και αυτοδίδακτους,
εμπνευσμένο από τον [Thonny](https://thonny.org).
**Δημιουργός:** Λέων Προκόπης, καθηγητής Πληροφορικής ΠΕ86

📖 **[Αναλυτικός Οδηγός Χρήσης (docs/USAGE.md)](docs/USAGE.md)** · Ύλη και θέματα προηγούμενων ετών: [panellhnies.gr](https://panellhnies.gr/mathima/programmatismos-ypologiston).

## Τι προσφέρει

- **Σύγχρονος editor (Monaco, ο editor του VS Code)**:
  - χρώματα κώδικα όπως στο IDLE (και στο βιβλίο)·
  - αυτόματη εσοχή μετά από `:`·
  - autocomplete με ελληνικές περιγραφές και snippets (`for`, `while`, `def`, ανάγνωση αρχείου, Tkinter, sqlite)·
  - εύρεση/αντικατάσταση, πολλαπλοί κέρσορες, folding, minimap·
  - καρτέλες για πολλά αρχεία·
  - κάθε νέο αρχείο ξεκινά με φόρμα σχολίων (Ημερομηνία, συμπληρωμένη αυτόματα, Άσκηση, Ονοματεπώνυμο).
- **Shell κάτω, όπως στον Thonny**:
  - η έξοδος του προγράμματος, και η είσοδος (`input`) γράφεται μέσα στη ροή·
  - μετά την εκτέλεση υπάρχει `>>>` με πρόσβαση στις μεταβλητές του προγράμματος και ιστορικό με ↑/↓.
- **Λάθη όπως στον Thonny**:
  - κόκκινο traceback με συνδέσμους που πηγαίνουν στη γραμμή·
  - η γραμμή του λάθους χρωματίζεται στον editor.
- **Βοηθός λαθών στα ελληνικά**:
  - εξηγεί τι σημαίνει το λάθος, προτείνει τι να δοκιμάσει ο μαθητής και δείχνει παράδειγμα «λάθος/σωστό»·
  - αναγνωρίζει τις συνηθισμένες παγίδες: `input()` σε αριθμητική πράξη χωρίς `int()`, `/` αντί για `//`,
    παρένθεση που δεν έκλεισε, καμπύλα εισαγωγικά και παύλες από αντιγραφή PDF, `lista = lista.sort()`,
    `.push()` σε στοίβα κ.ά.
- **Εκτέλεση βήμα-βήμα** με επιλογή ταχύτητας: **Γραμμή γραμμή** (προχωρά με το κουμπί «Επόμενη» ή F10),
  **Αργή**, **Μέτρια** ή **Κανονική**:
  - η γραμμή που εκτελείται φωτίζεται στον editor·
  - στις Μεταβλητές φαίνονται οι τιμές να αλλάζουν, μαζί με τις τοπικές μεταβλητές της συνάρτησης που εκτελείται·
  - η ταχύτητα αλλάζει και ενώ τρέχει το πρόγραμμα.
- **Ζωντανός έλεγχος σύνταξης**: τα λάθη σύνταξης υπογραμμίζονται καθώς γράφει ο μαθητής.
- **Πάνελ μεταβλητών** με τις τιμές και τους τύπους (και στα ελληνικά).
- **«Θέλω να θυμηθώ»** (F8): 45 σύντομα θέματα με τους βασικούς αλγορίθμους και τις εντολές της ύλης
  (ανάγνωση και εμφάνιση τιμών, συναρτήσεις, τιμή τερματισμού, έλεγχος εγκυρότητας, μέγιστο/ελάχιστο, πλήθος, άθροισμα,
  ποσοστό, λίστες, αναζήτηση, ταξινόμηση, συμβολοσειρές, στοίβα/ουρά, αρχεία, κλάσεις):
  - κάθε θέμα έχει παραδείγματα που μπαίνουν στον editor με ένα κλικ·
  - αναζήτηση χωρίς τόνους και φίλτρο επιπέδου (Βασικό / Προχωρημένο)·
  - το σήμα **Π** δείχνει σε ποια θέματα Πανελληνίων ΕΠΑΛ (2022-2026) ζητήθηκε κάθε αλγόριθμος·
  - το περιεχόμενο βρίσκεται στο `src/renderer/recall.md` και διορθώνεται εύκολα.
- **Ελληνικά με πλήρη υποστήριξη UTF-8**.
- **Παραδείγματα**: δυαδική αναζήτηση, ταξινομήσεις, στοίβα, ουρά, αρχεία, Tkinter, SQLite,
  και ένα πρόγραμμα με σκόπιμα λάθη για εξάσκηση με τον Βοηθό.
- **Τάξη** (στο τοπικό δίκτυο του εργαστηρίου, χωρίς internet):
  - ο καθηγητής βλέπει ζωντανά τον κώδικα κάθε μαθητή, μαζί με τη γραμμή του κέρσορα και τα λάθη σύνταξης·
  - ο μαθητής «σηκώνει χέρι» ✋ (F9) και ο καθηγητής το βλέπει αμέσως, με ήχο και ειδοποίηση·
  - **📺 Παρουσίαση:** οι μαθητές βλέπουν στην οθόνη τους τον κώδικα και το Shell του καθηγητή, ζωντανά. Με το
    «🔒 Όλοι εδώ» ο editor τους κλειδώνει όσο διαρκεί η παρουσίαση, και ο καθηγητής ορίζει αν επιτρέπεται η αντιγραφή·
  - η σύνδεση είναι κρυπτογραφημένη, και ο μαθητής συνδέεται μόνο στον υπολογιστή του καθηγητή του (δείτε παρακάτω).

## Απαιτήσεις

- Windows 10/11, ή Linux 64-bit (Ubuntu, Linux Mint, Debian και παρόμοιες διανομές).
- **Python 3** (3.10 έως 3.14) εγκατεστημένη από το [python.org](https://www.python.org/downloads/) (Windows)
  ή μέσω του package manager της διανομής (Linux).

## Εγκατάσταση στο εργαστήριο

Από τον φάκελο `dist/`:

- `EduPython3-<έκδοση>-setup.exe`: εγκατάσταση για όλους τους χρήστες, με συντόμευση και άνοιγμα αρχείων `.py`.
- `EduPython3-<έκδοση>-portable.exe`: ένα αρχείο που τρέχει χωρίς εγκατάσταση (π.χ. από USB).

Τα προγράμματα των μαθητών αποθηκεύονται από προεπιλογή στον φάκελο `EduPython3` μέσα στα Έγγραφα.

### Λειτουργία «Τάξη»

1. Στον υπολογιστή του καθηγητή: **Τάξη → Λειτουργία καθηγητή… → Έναρξη τάξης**, και μετά
   **Εξαγωγή classroom.json…**. Το αρχείο περιέχει το αποτύπωμα του κλειδιού του καθηγητή. Το κλειδί
   φτιάχνεται την πρώτη φορά και μένει στο προφίλ του.
2. Το `classroom.json` αντιγράφεται σε κάθε υπολογιστή μαθητή, στο `C:\ProgramData\EduPython3\classroom.json`
   (Linux: `/etc/edupython3/classroom.json`). Γράφει σε αυτή τη θέση μόνο ο διαχειριστής, οπότε ο μαθητής δεν μπορεί
   να βάλει δικό του «καθηγητή». Αντί για χειροκίνητη αντιγραφή, γίνεται και μαζί με την (σιωπηλή) εγκατάσταση:
   ```
   EduPython3-<έκδοση>-setup.exe /S /CLASSROOM=\\server\share\classroom.json
   ```
   Αν διδάσκουν περισσότεροι καθηγητές στο ίδιο εργαστήριο, ο καθένας κάνει «Εξαγωγή» στο **ίδιο** αρχείο:
   οι προηγούμενοι καθηγητές κρατιούνται και προστίθεται ο νέος.
3. Στην αρχή της ώρας οι μαθητές πατούν **Τάξη → Σύνδεση στην τάξη** και γράφουν το PIN που δείχνει η οθόνη του καθηγητή.

Ο καθηγητής βρίσκεται αυτόματα με broadcast στο τοπικό δίκτυο. Αν το δίκτυο το κόβει (π.χ. διαφορετικά VLAN),
η διεύθυνση IP του καθηγητή γράφεται στο `"hosts"` του `classroom.json`. Η «Εξαγωγή» βάζει εκεί τις τρέχουσες
διευθύνσεις του. Ο installer προσθέτει κανόνα στο Τείχος προστασίας των Windows για δίκτυα τομέα και ιδιωτικά δίκτυα
(TCP 47810, UDP 47811). Στην έκδοση portable τα Windows ζητούν την άδεια την πρώτη φορά.

Ο installer αφήνει τους απλούς χρήστες μόνο να διαβάζουν τον φάκελο `C:\ProgramData\EduPython3`. Με την έκδοση portable,
αυτό γίνεται με τις εντολές `icacls` του αναλυτικού οδηγού.

Πώς προστατεύεται ο κώδικας των μαθητών: η σύνδεση γίνεται με TLS, και ο υπολογιστής του μαθητή στέλνει κώδικα μόνο
αν ο server αποδείξει ότι έχει το κλειδί με το αποτύπωμα του `classroom.json`. Ένας άλλος υπολογιστής που τρέχει τη
«Λειτουργία καθηγητή», π.χ. ένας μαθητής με την έκδοση portable, δεν βλέπει τίποτα. Στους υπολογιστές των μαθητών
(με `classroom.json`) η Λειτουργία καθηγητή δεν εμφανίζεται καν. Ο μαθητής βλέπει πάντα κάτω δεξιά
πότε ο καθηγητής βλέπει τον κώδικά του και μπορεί να αποσυνδεθεί με ένα κλικ.

Αναλυτικός οδηγός, με χρήση στην ώρα, ασφάλεια, επίλυση προβλημάτων και πρωτόκολλο: [docs/classroom.md](docs/classroom.md).

## Εγκατάσταση σε Linux (Ubuntu, Linux Mint, Debian)

- `edupython3_<έκδοση>_amd64.deb`: εγκατάσταση για όλους τους χρήστες, με εικονίδιο στο μενού
  (**Προγραμματισμός → EduPython3**) και άνοιγμα αρχείων `.py`:
  ```
  sudo apt install ./edupython3_<έκδοση>_amd64.deb
  ```
- `EduPython3-<έκδοση>-linux-x64.tar.gz`: χωρίς εγκατάσταση. Αποσυμπίεση και `./edupython3.sh`.

Χρειάζεται εγκατεστημένη την Python 3 (3.10 έως 3.14):

```
sudo apt install python3 python3-tk
```

Η εφαρμογή βρίσκει μόνη της την Python 3 (3.10+).

## Για προγραμματιστές

```
npm install
npm start          # εκκίνηση
npm test           # tests (Node + Python 3)
npm run dist       # δημιουργία installer και portable .exe
npm run dist:linux # δημιουργία .deb και .tar.gz για Linux (χτίζεται και από Windows)
```

> Αν το `npm start` τρέχει μέσα από το τερματικό του VS Code και το Electron συμπεριφέρεται σαν Node,
> διάγραψε τη μεταβλητή περιβάλλοντος `ELECTRON_RUN_AS_NODE`.

| Αρχείο | Ρόλος |
|---|---|
| `backend/runner.py` | Εκτελεί το πρόγραμμα σε Python 3, πρωτόκολλο JSON-lines (έξοδος, είσοδος, λάθη, μεταβλητές, REPL) |
| `backend/checker.py` | Ζωντανός έλεγχος σύνταξης |
| `backend/_epal_util.py` | Κοινά: επιλογή κωδικοποίησης, compile χωρίς δήλωση coding |
| `src/main/` | Electron main: παράθυρο, μενού, αρχεία, διεργασίες Python |
| `src/main/classroom.js`, `classroomCert.js` | «Τάξη»: εύρεση με UDP, TLS server/client, classroom.json, κλειδί καθηγητή |
| `src/renderer/teacher.*` | «Τάξη»: η οθόνη του καθηγητή |
| `src/renderer/present.js` | «Τάξη»: η παρουσίαση του καθηγητή στην οθόνη του μαθητή |
| `build/installer.nsh` | Installer: κανόνας firewall, `/CLASSROOM=` |
| `src/renderer/editor.js` | Monaco: γλώσσα Python 3, θέματα IDLE, autocomplete, hovers |
| `src/renderer/shell.js` | Shell τύπου Thonny |
| `src/renderer/errorHelp.js` | Ο Βοηθός λαθών (κανόνες και ελληνικά κείμενα) |
| `src/renderer/pydocs.js` | Ελληνική τεκμηρίωση για autocomplete/hovers |
| `src/renderer/recall.md`, `recall.js` | «Θέλω να θυμηθώ»: περιεχόμενο (markdown) και πάνελ |
| `docs/USAGE.md` | Αναλυτικός οδηγός χρήσης για μαθητές και εκπαιδευτικούς |
| `scripts/build-linux.js` | Πακέτα Linux (.deb, .tar.gz) χωρίς fpm, ώστε να χτίζονται και από Windows |
| `scripts/linux/` | Εκκινητής της έκδοσης Linux χωρίς εγκατάσταση |
